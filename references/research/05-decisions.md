# 05｜真实决策与职业案例：Lulu Cheng Meservey

> 调研日期：2026-08-21。目标是为“可执行的方法论”保留可验证的案例，而非把客户宣传或结果归因于单一个人。除特别标注外，本文不采用知乎、微信公众号或百度来源。

## 证据口径

- **一手**：Meservey 的公开文章/访谈，或当时所在公司的公告与监管披露。
- **二手**：可靠媒体、客户/同行公开评价；可用于补充事实，不能单独证明她主导某项结果。
- **推断**：从上述材料归纳的工作方法；不等同于她的逐字表述。

## 案例 1｜Substack：在内容审核压力下，把“原则”变成可直接传播的立场（2021–2022）

**背景**  
Meservey 于 2021 年加入 Substack 担任 VP of Communications；平台当时因托管争议性 COVID 观点而面临要求移除/审查内容的压力。[Activision 任命公告（公司一手履历）](https://investor.activisionblizzard.com/node/35631/pdf)；[她在当时公开 thread 中的表态转载（含原话，二手载体）](https://greenwald.substack.com/p/the-pressure-campaign-on-spotify)。

**她采取/公开倡导的方法**  
1. 不把争议简化为“公关风险”，而是先宣布决策原则：以开放讨论为平台价值，极端情况才审核。  
2. 用可复述、可争辩的命题解释原则（例如“基于原则而非 PR 作决定”），将受众从“是否同意每一篇内容”转向“是否接受平台规则”。  
3. 由公司高管以第一人称公开承担立场，而不是只以匿名声明或新闻稿回应。

**证据与结果**  
她的公开表态可直接证明以上立场，但现有材料不足以量化其对留存、增长或舆情的因果效果。该案例更适合作为“高冲突议题先界定原则，再接受代价”的证据，而不是“强硬回应一定成功”的证据。

**可提炼步骤（推断）**  
`压力出现 → 识别不可让步的制度/价值原则 → 写成一句公众可检验的规则 → 由有决策权的人署名表达 → 同时明确极端例外与实际执行边界`。

**局限/反证**  
原则型沟通会主动放弃部分受众；若平台没有真实一致的执行记录，越明确的承诺越容易成为攻击证据。材料亦不能证明所有 Substack 内部人员或创作者认同该立场。

## 案例 2｜Activision Blizzard / Microsoft 收购：主动争夺“事实框架”（2022–2023）

**背景**  
Microsoft 拟收购 Activision Blizzard 的交易受到美、英、欧监管审查。Meservey 先任 Activision Blizzard 董事及 Workplace Responsibility Committee 成员，2022-10-06 转为新设的 EVP, Corporate Affairs & CCO，官方定位就是在交易前夕担任公司公共发声者。[公司公告（一手）](https://investor.activisionblizzard.com/node/35631/pdf)。

**她采取/公开倡导的方法**  
1. 将“外界认知与公司现实存在落差”设为沟通问题，而不是仅做交易流程公告；这是她在任命公告中的本人表述。  
2. 在监管争议期间使用社交平台及非传统、文化相关的切口发声；Axios 报道她曾在 X 点名 FTC、借《The Last of Us》引出竞争叙事，并称公司将更“outspoken”。[Axios 采访（二手，2023-02）](https://www.axios.com/2023/02/09/activision-blizzard-lulu-cheng-meservey)。  
3. 将公司、员工和数亿玩家作为需要被解释与动员的多重受众，而非只面向监管者/财经记者；这一受众设定可见于公司公告。

**结果**  
交易最终于 2023-10 完成；Axios 将她描述为协助公司穿越这宗约 690 亿美元、受多地监管挑战的收购。[Axios（二手）](https://www.axios.com/2023/12/16/activision-blizzards-lulu-cheng-meservey-wartime-communications)。但不能从现有公开证据推导“她的传播直接促成获批”：交易结果还取决于法律、商业让步和监管判断。

**可提炼步骤（推断）**  
`列出每个关键受众已相信的错误/不完整框架 → 找一项他们已关心的文化或产品证据作为入口 → 用高层第一人称重新解释事实 → 持续而非一次性地占据信息空间`。

**局限/争议**  
监管交易的公开挑衅可能激化关系，也会被解读为转移公司既有工作场所争议。把此案例复制为“点名监管者”的战术没有充分证据；可复用的层面是主动建立事实框架，而非某条具体帖文。

## 案例 3｜Rostra：把个人主张产品化为“founder-led / go direct”服务（2024–）

**背景**  
2024-03，Meservey 与 Toya Holness、Sergey Alexashenko 宣布成立 Rostra，面向科技创始人与初创公司；其公开论点是直接沟通对于建立运动、带人同行很关键。[Axios 对发布的报道（二手）](https://www.axios.com/2024/03/19/activision-blizzard-meservey-rostra-communications-firm)。Rostra 当前官网把服务对象明确为“帮助 founders go direct with their comms”。[Rostra 关于页（公司一手）](https://rostra.co/about/)。

**她采取/公开倡导的方法**  
1. 把“创始人自己负责叙事”定义为责任归属，而非渠道偏好：可以有团队、顾问和媒体，但不能把自己的声音与信念外包。此定义见 [Axios 对她观点的报道（二手，2025-03）](https://www.axios.com/newsletters/axios-communicators-2e1d8030-fab3-11ef-894b-d50ce5e27f0b)。  
2. 先建立自有平台和可识别的个人叙事，再将媒体/创作者作为放大器；她的《Go Direct》原文明确区分“不是拒绝帮助或放大，而是不依赖中介”。[《Go Direct》（一手）](../../sources/articles/go-direct.md)。  
3. 让沟通目标服从经营目标：她在《Comms Foundation #2》中给出“business objective → audience → belief → action”的公式，并建议把目标控制在少量、分别规划。[一手原文](../../sources/articles/comms-foundation-2-tactics.md)。

**结果与可验证边界**  
Rostra 官网列出 Palmer Luckey、Sam Altman、Brian Armstrong、Scott Wu 等人的正面评价及客户合作描述，这是**客户/公司自述**，可证明市场定位与认可，不足以独立证明具体业务成果或她对各公司全部决策的贡献。[Rostra（一手但带宣传性质）](https://rostra.co/about/)。

**可提炼步骤（强证据）**  
`选一个真实商业目标 → 精确选定需要采取行动的人群 → 定义他们必须相信的命题 → 选择创始人最自然、可长期持续的直接渠道 → 以第三方媒体/创作者扩大已清晰的叙事，而不让其替代叙事所有权`。

**局限/反证**  
Axios 同时指出，只依赖个人社媒/自有渠道很难覆盖更广受众，仍需借助其他人的关注者；这与“go direct = 只发自己的社媒”不同。[Axios（二手）](https://www.axios.com/newsletters/axios-communicators-2e1d8030-fab3-11ef-894b-d50ce5e27f0b)。创始人主导也会产生单点声誉风险，尤其在创始人缺乏可信度、纪律或愿意公开承担责任时。

## 案例 4｜Anduril 早期叙事：展示给真正的采用者，而非先求媒体许可（早期职业案例，时间待进一步核验）

**背景与证据**  
2026-08 的 David Senra 节目页（**二手节目简介，非完整逐字稿**）称：她在 TrailRunner 早期服务 Anduril；在 Palmer Luckey 刚离开 Facebook、媒体不愿公平报道时，团队不再优先请求报道，而是去 Quantico、Camp Pendleton、CIA 直接展示技术。[节目页](https://www.listennotes.com/id/podcasts/david-senra/lulu-cheng-meservey-founder-yAZ-73gEUo1/)。Rostra 官网中 Luckey 的推荐语称她帮助 Anduril 被“put on the map”，但同属营销性客户评价。[Rostra](https://rostra.co/about/)。

**可提炼的方法（暂定，需以完整访谈/一手材料复核）**  
当媒体框架先入为主且不服务于购买者/盟友决策时，先让最关键的专业受众接触可验证的产品或行动；让体验与可信第三方成为叙事证据，再寻求大规模扩散。

**结果/局限**  
现有材料无法确认该活动的具体日期、她的职责边界、展示次数或与公司增长的因果关系。因此只将它作为“目标受众优先于泛媒体”的候选案例，不能写成已证实的战绩。

## 跨案例的暂定方法论（只保留证据较强部分）

1. **事实/行动优先，传播其后**：先有能承载主张的产品、政策或具体行动，再做叙事与放大；传播不是修补空洞行动。此点也与她的文章中从商业目标倒推策略相一致。  
2. **指定真正的决策人，而不是“公众”**：写清他们下一步要做什么以及要先相信什么；不同目标分别做规划。  
3. **由拥有信念与信息的人承担话语责任**：创始人/负责人可以用支持团队，但不能把叙事判断完全外包。  
4. **在高冲突中先说原则与框架**：避免只对逐条指控被动答复；同时承认这会筛选受众、放大风险。  
5. **直接沟通不等于孤立沟通**：owned channel 用来保存控制权，第三方渠道用来扩张覆盖面。
